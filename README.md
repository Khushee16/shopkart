# ShopKart — Mini E-Commerce

A complete little storefront for fictional everyday tech: browse eight products, filter and sort, quick-view details, and manage a slide-in cart with quantities — all client-side.

## Features

- Product grid (8 fictional products) with category filter pills and price/rating sorting
- Product quick-view modal with quantity stepper and add-to-cart
- Slide-in cart drawer: quantity controls, line removal, live subtotal
- Free-shipping progress hint ($50 threshold)
- Mock checkout with order-confirmation state
- Cart persisted in localStorage across visits
- Responsive grid, drawer, and modal; Escape-to-close; staggered card animations

## Tech

HTML, CSS (custom properties, grid/flexbox), vanilla JavaScript. No frameworks, no build step — just open `index.html`. Photos via picsum.photos seeds.
